# ESP32-DIV V2 业务功能测试手册

> 版本：V2 固件 `ESP32-DIV_V2_20260923.bin`（编译日期 2026-09-23，SHA256 `0eca5a569791218ca642ba5259b2309fa75fa7a55100a0af28de093f53464bcd`）  
> 适用硬件：ESP32-S3 复刻板（模组 MCN16R8，8MB Flash，PSRAM 禁用），板卡宏 `BOARD_ESP32_DIV_V2`  
> 本文档面向出厂质检 / 维修 / 二次开发验收，覆盖全部 8 个主菜单、约 49 个业务功能及外设专项。

---

## 0. 重要合规与使用前提

ESP32-DIV 内置大量**射频发射与协议攻击**类工具（WiFi Deauth、BLE Jammer、SubGHz Jammer、Replay、MouseJack 等）。测试须遵守：

- 仅在**自有设备 / 屏蔽箱 / 远离公共无线环境**的场景下开启任何 Jammer、Deauth、Replay、Brute 类功能；
- 不得对第三方设备、公共网络、授权频段以外的目标进行测试；
- 射频功率与频段须符合所在地区法规；商用销售前确认当地无线电管理要求；
- 本手册仅描述**功能是否按预期工作**，不提供攻击目标与操作步骤的详细说明。

## 1. 设备与硬件概览

### 1.1 主控与平台

| 项目     | 规格                                                 |
| ------ | -------------------------------------------------- |
| MCU    | ESP32-S3（双核 LX7，240MHz）                            |
| Flash  | 8MB（分区方案 `huge_app`，app 区约 3.3MB）                  |
| PSRAM  | **禁用**（模组八线 PSRAM 占 GPIO33–37，开启会导致屏黑——编译硬约束）      |
| 显示     | 2.8" / 3.5" TFT 触摸（TFT_eSPI，旋转由 `TFT_ROTATION` 决定） |
| 触摸     | XPT2046 电阻触摸                                       |
| 键盘     | PCF8574 I/O 扩展（I2C 0x20），按键经 10k 对地、无独立 GPIO       |
| 电源管理   | IP5306（I2C 0x75），电池分压经 GPIO2 测电压推算电量               |
| USB 串口 | CP2102（部分板被刷成 11CA:0204，需飞线 TTL 救砖）                |

### 1.2 V2 引脚分配总表（接线核对用）

> ⚠ 下列引脚来自 `shared.h` 的 `BOARD_ESP32_DIV_V2` 分支定义。**SPI 总线存在多外设复用（SD / CC1101 / nRF24 / RFID 共用 GPIO11/12/13）**，靠各自片选（CS）分时，禁止把同一条线同时接两个模块的 CS。

| 外设          | 信号                           | GPIO                  | 备注                                     |
| ----------- | ---------------------------- | --------------------- | -------------------------------------- |
| 背光          | BACKLIGHT                    | 21                    | LEDC PWM 调光                            |
| 触摸          | XPT2046_CS                   | 33                    |                                        |
| 触摸          | XPT2046_MOSI                 | 32                    |                                        |
| 触摸          | XPT2046_MISO                 | 39                    | **与 USB_DETECT 同脚 39**，分时复用            |
| 触摸          | XPT2046_IRQ                  | 36                    |                                        |
| I2C         | SDA / SCL                    | 8 / 9                 | PCF8574(0x20) + IP5306(0x75)，板载 10k 上拉 |
| SD 卡        | CS / MOSI / MISO / SCLK / CD | 5 / 11 / 13 / 12 / 38 | 共享 SPI 总线                              |
| RFID PN532  | SCK / MISO / MOSI / CS       | 12 / 11 / 13 / **1**  | **SPI 模式**；RSTPDN 硬件 10k 上拉 3V3（固件不驱动） |
| CC1101      | SCK / MOSI / MISO / CS       | 12 / 11 / 13 / 5      | GDO0=6，GDO2=3                          |
| SubGHz 数据   | TX / RX                      | 6 / 3                 | 接 CC1101 GDO0/GDO2                     |
| nRF24 #1    | CE / CSN                     | 15 / 4                |                                        |
| nRF24 #2    | CE / CSN                     | 47 / 48               |                                        |
| nRF24 #3    | CE / CSN                     | 14 / 21               |                                        |
| nRF24 共享SPI | SCK/MISO/MOSI/SS             | 12/13/11/4            | 与 SD/CC1101 同名网络一致                     |
| GPS         | RX / TX                      | 41 / 42               | UART2（ATGM336H/Neo-6M 类）               |
| IR 收发       | RX / TX                      | 40 / 46               | TX=46 为 strapping 脚，禁止外加上拉             |
| 电池          | ADC                          | 2                     | VBAT→100k→GPIO2←(分压)→GND，实测比例约 6.6:1   |
| USB 检测      | DETECT                       | 39                    | 高有效（插入=高），与触摸 MISO 同脚                  |
| 蜂鸣器         | —                            | 2（硬件）/ 固件 -1          | 硬件预留 IO2，**固件当前未驱动**（`BUZZER_PIN=-1`）  |

### 1.3 供电与电池

- 电池经 IP5306 升压/充电管理；拔 USB 后电源存在约 15ms 塌坑（保护板特性），固件看门狗/电容补偿应对。
- 电量百分比由 GPIO2 分压 ADC 电压经 21 点锂电 OCV 曲线推算（非 IP5306 四档粗估）。
- USB 插入检测=GPIO39 高电平 → 状态栏电池框右侧显示黄色插头。

## 3. 通用操作与交互说明

### 3.1 菜单导航

- 主菜单 8 项，触摸点击进入对应子菜单。
- 子菜单多为**列表 + 底部翻页/返回栏**；WiFi、Bluetooth 为多页（见下表）。
- `More` 为三层网格：首页(IR Remote / RFID-NFC / GPS / Main Menu)，各层再展开。

| 主菜单                    | 子菜单功能数                         | 页数                   |
| ---------------------- | ------------------------------ | -------------------- |
| WiFi                   | 11（含 Back）                     | 2 页（页0: 8 项，页1: 3 项） |
| 2.4GHz(nRF24)          | 7（含 Back）                      | 1 页                  |
| More → IR / RFID / GPS | IR:4 / RFID:9 / GPS:3（均含 Back） | 网格切换                 |
| Bluetooth              | 9（含 Back）                      | 2 页（页0: 8 项，页1: 1 项） |
| SubGHz                 | 6（含 Back）                      | 1 页                  |
| Tools                  | 5（含 Back）                      | 1 页                  |
| Settings               | 全屏 AppSettings                 | —                    |
| About                  | 静态页                            | —                    |

### 3.2 触摸与按键

- 触摸：点击列表项进入；底部导航栏 5 个按钮（图标+Main Menu / 翻页）。
- 按键：经 PCF8574（I2C 0x20）轮询，10k 对地；用于翻页/确认/返回。**按键无独立 GPIO，固件周期性读 PCF8574 原始字节**。

### 3.3 息屏（Screen Off）行为

- **触发**：Settings 内「息屏超时」档位到期且无操作。
- **表现**：整屏降为最低亮度，中央显示**竖版电池图标 + 居中大数字电量% + 下方黄色充电插头**（区域刷新，仅电池框与插头区域重绘）。
- **唤醒**：触摸/按键任意操作唤醒，界面整体重绘。
- **豁免**：38 项「动态画面功能」（实时列表/波形/扫描/计数，见 §6 标注）运行期间**不自动息屏**，避免活画面被打断。

### 3.4 退出 / 返回

- 各功能屏底部有返回/退出按钮；部分功能（扫描类）需先停止再退出。
- 返回主菜单路径：`Back to Main Menu` 或底部 Main Menu 图标。

## 8. 异常现象与排查速查表

| 现象                       | 根因                        | 处理                                            |
| ------------------------ | ------------------------- | --------------------------------------------- |
| 进 RFID 卡死/触摸按键不动         | 早期 I2C 总线被 PN532 拖死       | **已改 SPI**；若仍卡，查 MISO/MOSI 交叉、RSTPDN 上拉       |
| 提示「未找到模块」                | MISO/MOSI 接反（与 SD 同名网络相反） | 对调 MISO/MOSI 两根线                              |
| 上电按键全废                   | GPIO1(RSTPDN) 未初始化        | 已修：setup 首件释放 PN532 复位（硬件上拉后无需驱动）             |
| 息屏后点击卡住                  | 唤醒未刷新活动时间戳                | 已修：唤醒即重绘                                      |
| 电池 75%/4.146V 不准         | 线性粗估/退回 IP5306 四档         | 已修：21 点锂电曲线 + 中位数采样                           |
| 编译 core.a undefined      | IDE 缓存 core.a 残缺          | 改名 `core.a` 强制重建，或用 arduino-cli 干净 build-path |
| 屏黑                       | PSRAM 开启（占 33–37）         | 编译必须 `PSRAM=disabled`                         |
| 主固件加 --warnings=all 编译失败 | platform.txt 自带 -Werror   | 不要加该开关                                        |
| 固件 >1.66MB 溢出            | 分区非 huge_app              | 用 `huge_app` 分区                               |

## 10. 备注与版本记录

- 本手册基于当前 V2 源码（shared.h / ESP32-DIV.ino / rfid.cpp / utils.cpp，mtime 2026-09-23 14:35–14:41）编写，对应固件 `ESP32-DIV_V2_20260923.bin`。
- 功能清单取自 `ESP32-DIV.ino` 顶部各 `*_submenu_items[]` 数组与 `config.h` 命名空间；共 8 主菜单、约 49 业务功能。
- 动态画面免息屏名单（`kDynamicScreenFeatures`，38 项）与菜单文字强耦合，改菜单文字须同步，否则漏保护。
- 蜂鸣器为硬件预留（IO2），固件 `BUZZER_PIN=-1` 未启用；如需启用改为 2 并重编。
- 电池 ADC 与 USB 检测复用 GPIO2 / GPIO39，测试时勿在 USB 插入状态下强制触摸 MISO 采样造成冲突。
