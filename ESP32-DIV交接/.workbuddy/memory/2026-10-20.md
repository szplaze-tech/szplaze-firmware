
## 按键音"没存住"误报（2026-10-20）
- 现象：Settings 触屏把按键音点为关→Save→Back，感觉没存住。
- 根因：设置链路无 bug（applyKeyBeep→dirtySettings→settingsSave 写 /config/settings.json，load/save 均含 keyBeepEnabled，uiBeep() 有门控 utils.cpp:832）。真凶 = 上次 IO45 排查加的开机自检音 uiBeepSelfTest()（ino:4944），故意无视 Key Beep 开关每 boot 无条件响 300ms。
- 修复：调用包进 `#if DIAG_PRINTS_ENABLED`（ino ~4944），DIAG 收尾改 0 后自检音随之消失；函数本体保留供以后诊断。
- 验证：保存时底部应现 "Saved"（若 "Save FAILED" = SD 卡问题）；重启后那声 300ms 是自检音，按键音以按键是否响为准。

## Settings 开关行触屏双翻 bug（2026-10-20）
- Key Beep / Auto Scan / Language 三行触屏只有 120/200ms 时间去抖、无沿检测：handleTouch 2ms 轮询，手指按住超阈值会再翻一次，点一下翻两次弹回原值 → Save 显示 No changes，被感知为"没存住"。
- 修复 utils.cpp handleTouch：加 `static bool switchArmed`（无触摸时复位 true，触发后置 false），三行统一 armed 沿触发；Accent 行原有 accentArmed 同款模式。Theme 行双目标且重复 apply 同值是 no-op，不需改。
- 物理按键路径（左=关/右=开，直接赋值非 toggle）无此问题。

## 开机自检音移除（2026-10-20）
- 用户确认开关行修复生效，但开机仍响一声（DIAG=1 时自检音仍在）。蜂鸣器硬件已验证 OK，直接删除 setup() 末尾 uiBeepSelfTest() 调用（ino ~4941，连同 #if DIAG_PRINTS_ENABLED 包裹）；函数本体保留在 utils.cpp 供以后诊断临时挂回。
- DIAG_PRINTS_ENABLED 仍为 1（shared.h:925，[BAT]/[UIBEEP] 串口行还在）；出正式版时再收尾关 0。
