## RFID 门禁卡克隆"第7块读失败"——部分克隆 + 常见密钥表（16:5x）
- 症状：克隆门禁卡，读到第 7 个块报 "Some blocks/pages did not read. Check keys or tag damage"。
- 根因：不是 bug。读块顺序 0,1,2,4,5,6,8…，第 7 个读的是**块 8 = 扇区 2**；门禁卡扇区 2 用了**非默认密钥**，而 sessionClone 只试 FFFFFFFFFFFF（A/B 各一次），鉴权失败 → readOk=false 一票否决整个克隆。
- 改动（rfid.cpp sessionClone，7 处）：
  1. 新增 kCommonKeys 常见密钥表（12 个：FF/00/MAD A0A1../NDEF D3F7../及常见公共值），按扇区试 A、B 两类。
  2. 新增按扇区状态：s_srcKeyA/B[16][6]、s_srcKeyA/BValid[16]、s_srcSectorOk[16]、sectorsOkCount。
  3. Classic 读循环重写：逐扇区先做密钥发现（首个数据块上试表），成功后用该密钥读 3 个数据块；读不全的扇区标记失败但**不再中止整个流程**。
  4. 判定门：sectorsOkCount==0 → 报 "No sector key matched (common keys tried)"；<16 → 日志 "[!] Partial read: n/15 sectors"。
  5. 写入循环：`!s_srcSectorOk[sector]` 的扇区跳过（保留目标卡出厂内容），sectorsSkipped 计数；目标卡鉴权顺序 FF A → FF B → 00 → 源keyA → 源keyB（后备）。
  6. magic UID 克隆加守护 `magic && s_srcSectorOk[0]`（块 0 的 SAK/ATQA 字节来自源数据，扇区 0 未读上会写垃圾）。
  7. summary 追加 "Sectors cloned: n/15 (skipped m, key unknown)"；introFoot 文案更新。
- 使用须知：若门禁读卡器只校验 UID，用 Gen2 magic 卡 UID 克隆即可用；部分克隆出的卡扇区 2 保持出厂。密钥完全自定义的卡本工具打不开（需 nested/darkside 破解，PN532 不具备）。
- 用户自行编译验证。

## 克隆结果解读 + 统计口径修正（17:15）
- 实测结果：source f1d549cf / blank ccabc806 / write ops OK=1 / magic not detected / skipped 9。
