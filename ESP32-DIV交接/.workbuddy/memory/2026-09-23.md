## BLE Rubber Ducky 脚本语法澄清 + 示例
- 用户确认手机连上后不知下一步；经查 `ducky.cpp`：`ESP32S3 Ducky` 是 BLE HID keyboard peripheral，脚本预置在 SD 卡 `/ducky/*.duck|*.txt`，连接只是建立注入目标，必须设备上选脚本按 Run 触发注入。
- 语法为 ducky.cpp 子集（execLine 解析）：`REM`(注释，REM Name:/REM Description: 被详情页提取)、`STRING`(仅 ASCII，大写自动 Shift，**不支持中文**)、`ENTER`/`RETURN`、`DELAY <ms>`、`DEFAULT_DELAY <ms>`、`WAIT_FOR <ms>`、`GUI/WIN/WINDOWS <键>`(GUI 不带参=Win+R)、`CTRL/CONTROL <键>`、`ALT <键>`、`SHIFT <键>`(支持多修饰连写如 `CTRL ALT DEL`)、单键 `TAB/ESC/SPACE/BACKSPACE/DELETE/UP/DOWN/LEFT/RIGHT/HOME/END/PGUP/PGDN/F1-F12`、`REPEAT <n>`。
- 交付两个示例：`ESP32-DIV-main/ESP32-DIV/ducky_examples/test_hello.duck`(跨平台基础验证) 与 `win_calc.duck`(Windows 计算器演示，仅电脑 host 有效)。用户拷到 SD 卡 `/ducky/` 即可。
- 续：应要求按平台拆三脚本 `win_demo.duck`(Win+R→记事本打字)、`android_demo.duck`(纯 STRING+ENTER，手机组合键无效)、`ios_demo.duck`(iOS 将 GUI 映射为 Cmd 键，Cmd+Space 开 Spotlight)。记：`REM` 注释可中文，`STRING` 仅 ASCII；手机 host 对组合键支持差。
